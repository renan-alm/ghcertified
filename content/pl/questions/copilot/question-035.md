---
title: "Pytanie 035"
question: "Tworzysz aplikację w Kotlinie. O czym musisz pamiętać, używając GitHub Copilot?"
---

> https://learn.microsoft.com/en-us/training/modules/github-copilot-across-environments/2-code-completion-with-git-hub-copilot
1. [x] Kotlin nie jest uwzględniony w językach, w których GitHub Copilot oferuje mocne wsparcie. W związku z tym sugestie kodu mogą nie być takiej samej jakości jak sugestie kodu w lepiej wspieranych językach, takich jak Ruby, Java czy C#.
1. [ ] Kotlin nie jest uwzględniony w językach, w których GitHub Copilot oferuje mocne wsparcie. W związku z tym GitHub Copilot nie będzie w stanie wyjaśnić ani naprawić kodu.
1. [ ] Kotlin nie jest uwzględniony w językach, w których GitHub Copilot oferuje mocne wsparcie. W związku z tym GitHub Copilot nadal może wyjaśniać lub naprawiać kod, ale nie będzie w stanie dostarczać sugestii kodu.
1. [ ] Żadne nie jest poprawne, ponieważ Kotlin jest uwzględniony w językach, w których GitHub Copilot oferuje mocne wsparcie.
