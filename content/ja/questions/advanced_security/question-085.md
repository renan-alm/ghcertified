> https://docs.github.com/en/code-security/code-scanning/managing-code-scanning-alerts/assessing-code-scanning-alerts-for-your-repository
- [x] リポジトリのセキュリティタブでアラートの概要を表示するには、書き込み権限が必要です。
- [x] リポジトリに対する読み取り権限を持つ誰もが、Pull Requestでコードスキャンの注釈を見ることができます。
- [ ] Pull Requestでコードスキャンの注釈を表示するには、書き込み権限が必要です。
- [ ] リポジトリに対する読み取り権限を持つ誰もが、セキュリティタブでコードスキャンアラートを見ることができます。
- [ ] リポジトリ所有者のみが、セキュリティタブでコードスキャンアラートを見ることができます。
