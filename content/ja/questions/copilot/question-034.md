- [x] プロンプトは保持されませんが、使用状況分析データはデフォルトで保持されます。
- [x] オプションの使用状況分析データの収集をオプトアウトすることが可能です。
- [x] Copilot CLI が生成した回答は、各提案後に確認することができます。
- [ ] プロンプトと使用状況分析データはどちらもデフォルトで保持されます。  
> プロンプトはデフォルトで保持されません。  
- [ ] 使用状況分析データは匿名化されているため、オプトアウトすることはできません。  
- [ ] GitHub Copilot CLI はコマンドを説明または提案することしかできず、ユーザーの代わりに実行することはできません。
