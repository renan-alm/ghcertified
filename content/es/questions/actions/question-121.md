---
title: "Pregunta 121"
question: "¿Qué es cierto sobre las variables predeterminadas? (elige tres)"
---


> https://docs.github.com/en/actions/reference/workflows-and-actions/variables
- [x] Las variables de entorno predeterminadas son establecidas por GitHub y no definidas en un workflow
- [x] La mayoría de las variables de entorno predeterminadas tienen una propiedad de contexto correspondiente
- [x] Actualmente, el valor de la variable de entorno predeterminada CI puede ser sobrescrito, pero no se garantiza que siempre sea posible
- [ ] Puedes agregar una nueva variable de entorno predeterminada agregando el prefijo “GITHUB_” a ella
- [ ] Las variables de entorno predeterminadas siempre tienen el prefijo “GITHUB_”
- [ ] Las variables de entorno predeterminadas pueden accederse usando el contexto env
